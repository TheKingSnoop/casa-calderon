# 0001 · Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-12
- **Deciders:** Project lead

## Context

Several people (four family members, plus an AI coding assistant) will work on this project over time. Without a record, the reasons behind choices get lost and get re-argued.

## Decision

We will record significant decisions as lightweight ADRs in `docs/decisions/`, using the template in `0000-template.md`.

## Consequences

- New contributors can read the decision history to get up to speed.
- Small overhead per decision. We only write ADRs for decisions that are significant or likely to be questioned.
